# 0x0e. C - Function pointers

Implements and uses function pointers in C: passing functions as arguments, iterating over arrays with a callback, searching arrays with a comparator function, and building a simple calculator whose operator dispatch is driven by a lookup table of function pointers rather than a switch statement.

All code is compiled with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89` and follows Betty coding style.
