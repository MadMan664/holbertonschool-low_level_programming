# AI Memory Visualizer + Valgrind Tracer

Analysis of stack vs. heap memory behavior, pointer aliasing, and Valgrind
diagnostics in four intentionally buggy C programs, using Claude as a
first-pass analysis assistant and independently verifying/correcting its
explanations against real program and Valgrind output.

See `analysis/memory_maps.md`, `analysis/valgrind_analysis.md`, and
`analysis/crash_report.md`.
