# 0x10. C - argc, argv

Introductory programs using command-line arguments (`argc`/`argv`): printing the program's own name, counting and printing arguments, and two small argument-driven calculators (multiplication of two numbers, and summing an arbitrary list of positive numbers with input validation).

All code is compiled with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89` and follows Betty coding style.
