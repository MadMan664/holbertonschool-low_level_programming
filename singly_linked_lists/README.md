# C - Singly linked lists

Implementation of a singly linked list (`list_t`) storing malloc'ed strings, covering printing, length counting, insertion at head and tail, and full list deallocation.

## Files

- `lists.h` — struct/typedef definition and function prototypes
- `0-print_list.c` — prints every node, returns node count
- `1-list_len.c` — returns node count without printing
- `2-add_node.c` — inserts a new node at the head
- `3-add_node_end.c` — inserts a new node at the tail
- `4-free_list.c` — frees every node and its duplicated string
